# lyrics/ — 歌词的卡点数据（文本，进 git）

[English](README.md)

| 文件 | 内容 | 谁改 |
|---|---|---|
| `timing.txt` | **逐拍时间轴，唯一的编辑源**：一拍一行，时刻 / 显示的字 / 读音。句子、读音、时刻都以它为准 | 打点工具（`/lyric-tool/`），也可以手改 |
| `kana.txt` | 歌词 + 汉字读音，一句一行（`漢字{よみ}`）。第一次估计前：`lyrics.py --init` 生成底稿，补上读音；有了时间轴以后：它是时间轴的摘要，保存时自动重写 | 第一次估计前手改；之后不用动 |
| `lyrics.js` | 由 `timing.txt` 生成的数据，网页直接载入。各版本 `js/lyrics.js` 是它的快照 | 生成的，不要手改 |
| `backup/` | 打点工具每次保存前留的备份（不进 git） | 自动 |

改句子、改读音、合并 / 拆开 / 增删句子都在打点工具里做。句数变了以后句子的编号会变，分镜里按句号写的地方要跟着改。

`timing.txt` 里每句的状态写作 `estimated`（自动估计、还没听写确认）或 `confirmed`（确认过）。

格式说明和全部命令在 [lyric-tool/lyrics.py](../lyric-tool/lyrics.py) 开头（英文）。

`timing.txt` 里有完整歌词。歌词有版权时，仓库不要公开；或者把这个文件夹也加进 `.gitignore`。
