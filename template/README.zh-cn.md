## 文件

| 文件 | 内容 |
|---|---|
| `index.html` `style.css` | 页面和播放器外壳。一般不用动 |
| `lang.zh-cn.js` | 播放器自己的文字（开始画面、控制条、启动时的提示）的简体中文；和视频内容无关 |
| `js/core.js` | 基础：缓动、`pop()`、确定性随机、颜色、中性灰的调色板 `C`、节拍 `AU`、歌词时刻 `LT/LE/LL/LCT`、切点 `CUT/DOWN/LCUT`、字体、`txt()` |
| `js/fx.js` | 可选的图形小工具：填色和渐变、颗粒、网点、圆环、星空、放射线、集中线…… |
| `js/type.js` | 动态字幕：`lyric(c, t, cfg)`，每个字在唱到它的那一刻出现；`CAP()` 一行字幕的配置；`typeOn()` 自己写的字逐个弹出 |
| `js/assets.js` | 图片：`IMG` 里写每张图的焦点；`card()` 画卡片；没有图时画一个朴素的带编号的占位图 |
| `js/scenes.js` | **分镜脚本 = 视频内容**。`SEG` 里一项是一个镜头 |
| `js/main.js` | 合成、转场、播放器、导出接口 `window.MV` |
| `js/lyrics.js` | 歌词数据的快照（`lyric-tool/lyrics.py` 生成并拷进来，不要手改） |
| `images.json` | 这一版用了哪些编号的图、各是池里哪个文件（`pic-tool/pic.py` 维护，不要手改） |

图形小工具（`fx.js`、`type.js` 里的字幕动画、`card()`、`core.js` 里的调色板和字体、`main.js` 里的转场）和示例分镜是示例，不是风格：
作品可以用、改或者换掉。

## 三条规矩

1. **画面只依赖时刻 `t`**。不存上一帧的状态，随机用 `hash()`。这样拖动、暂停、逐帧导出、分段并行导出的画面才完全一致。
2. **时刻用歌词和节拍的函数写**（`LT(句, 短句)`、`LCT(句, 第几个字)`、`BT(拍)`、`LCUT(句)`、`DOWN(t)`……），不写死秒数。时间轴修正之后画面自动跟上。
3. **图用键名引用**（`card(c, 'hero', …)`），文件名只出现在 `images.json`。重画一张图不用动分镜。
