## Files

| File | Contents |
|---|---|
| `index.html` `style.css` | The page and the player shell. Normally left alone |
| `lang.zh-cn.js` | Simplified Chinese for the player's own text (start screen, controls, start-up notes); it has nothing to do with the content |
| `js/core.js` | Basics: easing, `pop()`, deterministic random, colours, the neutral grey palette `C`, the beat `AU`, lyric times `LT/LE/LL/LCT`, cut points `CUT/DOWN/LCUT`, fonts, `txt()` |
| `js/fx.js` | Optional graphic helpers: fills and gradients, grain, halftone dots, rings, starfield, rays, speed lines … |
| `js/type.js` | Kinetic lyrics: `lyric(c, t, cfg)`, each character appearing at the moment it is sung; `CAP()` the config for a one-line caption; `typeOn()` your own text popping in character by character |
| `js/assets.js` | Images: `IMG` holds each image's focus point; `card()` draws a card; when an image is missing, a plain numbered placeholder is drawn instead |
| `js/scenes.js` | **The storyboard = the content of the video.** Each entry in `SEG` is one shot |
| `js/main.js` | Compositing, transitions, the player, the export interface `window.MV` |
| `js/lyrics.js` | A snapshot of the lyric data (generated by `lyric-tool/lyrics.py` and copied in; do not edit by hand) |
| `images.json` | Which numbered images this version uses and which pool file each one is (maintained by `pic-tool/pic.py`; do not edit by hand) |

The graphic helpers (`fx.js`, the lyric animations in `type.js`, `card()`, the palette and fonts in `core.js`, the
transitions in `main.js`) and the demo storyboard are examples, not a style: a work may use, change or replace them.

## Three rules

1. **The picture depends only on the time `t`.** No state kept from the previous frame; randomness via `hash()`. Only then
   are scrubbing, pausing, frame-by-frame export and parallel segmented export exactly identical.
2. **Times are written through the lyric and beat helpers** (`LT(line, phrase)`, `LCT(line, nth character)`,
   `BT(beat)`, `LCUT(line)`, `DOWN(t)` …), never as hard-coded seconds. When the timeline is corrected, the picture
   follows by itself.
3. **Images are referred to by key** (`card(c, 'hero', …)`); file names appear only in `images.json`. Redrawing an image
   doesn't touch the storyboard.
